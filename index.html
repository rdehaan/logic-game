    Errors and warnings
    
        
    
          These are problems in the programs that clingo reported, or that
          the game noticed (for example, a program that uses a special
          predicate it does not get, or derives one that is not passed on).
          Click on one to go to the program.
        
    
        
      
      
      

      
      Game output
      
      
      
        Below you will find, for each time step (most recent step at the top),
        what facts were fed into the player program,
        based on (i) the state of the game that is observable to the player,
        and (ii) the player's memory.
        It also shows what came out of the step:
        the player's moves, the updates to the player's memory,
        and the next state of the game computed by nature.
        If a program had no answer sets or contained an error,
        this is reported as well.
        Click on a step to see the board as the player saw it in that step
        (also with the slider under the board, while the game is paused or
        after it ended); the Step button plays one step at a time.

        Keep your work in a file
        
      
        
        The project file holds your current version, all snapshots (with
        their notes and test results) and the original game. Save it wherever you
        keep your files; load it below on any computer to go on where you left off.
        Work saved in a browser can get lost (for example when the browser's
        data is cleared), so download your project now and then.
      
        
      
        
      
      

      
        Load a file
        
      
        
        A project file, a game file (like the examples), or a backup of everything.
        Your current work on that game is kept as a snapshot first.
      
        
      
        
        
        
      
        
      
        

      
        Share current game
        
      
        
        This creates a link that contains the whole game (all programs,
        including your strategy, but not your snapshots). Whoever opens the link
        gets their own copy of the game. The game is not uploaded anywhere: it is
        stored in the link itself.

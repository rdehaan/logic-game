Auxiliary, level generation & visibility programs

The auxiliary program can be used to define helping predicates that are used in the other programs. This program is added to the other programs when they are used.

The level generation program specifies how levels are generated. An answer set for this program encodes the level using atoms with predicate names at, setting, and decorate.

The visibility program defines what parts of the game are observable to the player. The predicate name observe is used for this. It may also derive atoms over decorate, which are only used to visualize the game and are not passed on to the player.

All programs of the game rules are locked to generate a level and to play (use Unlock to edit at the top of the Game rules tab). When the auxiliary or level generation program changed, locking them again removes the level, which was made with the old programs.

For more details, see the Instructions tab.

Nature's moves

This program expresses how the game progresses from one state to the next. An answer set of this program, restricted to atoms over the predicate next, constitutes the next state of the game, where these atoms are translated to use the predicate at instead of next.

If the answer set contains the atom wipe_player_memory, the player's memory is wiped: the player starts the next time step with an empty memory.

For more details, see the Instructions tab.

Winning conditions

This program determines whether the player wins or loses the game, at each time step, or whether it continues.

If an answer set of the program contains any atoms over lose, the player loses the game. Otherwise, if this answer set contains any atoms over win, the player wins. Otherwise, the game continues. This is checked at the start of each time step, before the player moves.

For more details, see the Instructions tab.

Player strategy

This program specifies what move(s) the player performs at each time step, and how the player's memory is updated. The program gets what the player can observe (atoms over observe), the level settings (atoms over setting), the player's memory (atoms over memory), the current time (current_time(t)), and the auxiliary program. An answer set A of the resulting program is taken. This answer set restricted to atoms over do constitutes the moves that the player performs. This answer set restricted to atoms over remember and forget specifies how the player's memory changes.

The player's memory in the next time step consists of (i) all atoms memory(M) such that forget(M) does not occur in A, and (ii) all atoms memory(M) such that remember(M) occurs in A, unless nature wipes the player's memory, in which case the player's memory in the next time step is empty.

For more details, see the Instructions tab.

Grading

Loading. In Canvas, Download submissions of the assignment gives one zip file with the files of all students, named after the student (e.g. doejane_12345_678901_hw3.zip). Load that file as it is: the files are grouped per student, zip files in it are unpacked, and the game file and the PDF of each student are found.

Grading a student. Click on Grade in the list: the game of the student is loaded into the page (as with any game: play it, step through it, look at the Debug tab; your changes to it do not change what was handed in). Their PDF is shown next to the rubric. Test and measure plays the game on new levels and suggests a score for the items of the rubric, with the evidence. Suggestions are only suggestions: Accept the suggestions takes them over for the items you did not decide yet, and you can change every item.

Looking closer. Show everything on the board (under the board) also shows the objects the player does not see, faded. In the test results, any level can be loaded onto the board, and the first levels that were generated are shown small, to see whether levels are random.

Feedback. Write a comment (or insert standard comments), add notes on lines of the programs (with the program and line of the cursor in an editor), and add pictures of the board (as it is shown at that moment). Download the feedback as a PDF, a web page or text, for one student or for all of them (a zip file), and the grades of all students as a CSV file.

Keeping your work. Everything is kept in this browser. Export the grading gives a file with all of it (but not the PDF files of the students); another grader can import it: students they do not have yet are added, and for the others the version that was changed last is kept.

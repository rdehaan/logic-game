    Errors and warnings
    
        
    
          These are problems in the programs that clingo reported, or that
          the game noticed (for example, a program that uses a special
          predicate it does not get, or derives one that is not passed on).
          Click on one to go to the program.
        
    
        
      
      
      

      
      Game output
      
      
      
        For each step of the last game: what went into the player's program
        (what the player observed, and the player's memory), what came out
        (the player's moves and the updates to the memory), and the next state
        of the game that nature computed (and how long clingo took).
        If a program had no answer set or contained an error, this is reported as well.
        The step shown is the one of the board: move through the game with the slider.
        The facts that went into and came out of each program are shown in a locked
        editor each, one fact per line. Hover over a fact to see its cell on the board,
        or over a cell to see the facts about it.

        Snapshots of this game 
        
      
          Snapshots are versions of your work that you can compare and go back to.
        
      
        
      
          
          
          
      
            
            
          
      
        
      
        
      
          The page also keeps snapshots by itself: every 10 minutes while you edit, when you
          test your strategy (with the result), and before your current version is replaced
          (by restoring an older version, taking a program from another one, going back to
          the original, loading a file, or changes to the files of a linked folder).
          Only the newest 20 of these are kept; give one a name or a note to keep it.

        Keep everything in a file: the project file (to go on working on another computer)
        
        
          The project file holds your current version, all snapshots (with
          their notes and test results) and the original game. Save it wherever you
          keep your files (for example in your Google Drive or OneDrive folder, or on a
          USB stick), and load it above on any computer to go on where you left off.
          Work saved in a browser can get lost (for example when the browser's
          data is cleared), so download your project now and then.
        
        
        
        
        
        
        
        
          As a folder: one plain clingo file per program (strategy.lp, nature.lp, …),
          for your own editor, for git (a change shows up per program), and for the
          command-line version of the game (see Playing on your own computer in the
          Instructions tab).
          Snapshots are not in the folder: use git (or the project file) for versions.
        
        
      
        

      
        
        Work in a folder on your computer 
        
        
          
        
            Link the page to a game folder on your computer (for example, a folder in your git repository).
            Every change you make here is saved into its files, and changes to the files
            (in your own editor, or by git) show up here within a few seconds.
            An empty folder gets the current game.
          
        
          
        
          
          
          
        
        
        
        
          This browser cannot link the page to a folder (Chrome and Edge can).
          You can download the game as a folder (.zip) with the project file above, and load a folder at the top.
        
        
      
        

      
        
        Share a link to this game
        
        
          This creates a link that contains the whole game (all programs,
          including your strategy, but not your snapshots). Whoever opens the link
          gets their own copy of the game. The game is not uploaded anywhere: it is
          stored in the link itself.
